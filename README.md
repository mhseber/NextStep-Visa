# 🌍 NextStep Visa Service Portal

A mini web application for exploring visa services, viewing process steps, and tracking application progress.  
Built with **React + TailwindCSS** for a modern, responsive user experience.

---

## 🚀 Features

- ✅ Beautiful Hero Section
- ✅ Visa services exploration
- ✅ Step-by-step application tracking
- ✅ Responsive design (Mobile → Tablet → Desktop)
- ✅ Clean UI with TailwindCSS

---

## 🛠️ Tech Stack

- **React.js** (Frontend Framework)
- **React Router** (Routing)
- **TailwindCSS + DaisyUI** (Styling)
- **React Icons** (Icons)
